# Yakusoku for Cursor

Plan a wedding in [Yakusoku](https://yakusoku.com.au) from Cursor: guests and RSVPs, seating, menu, budget, tasks, calendar, vendors, photos, the gift registry and messages. Vendors manage their listings, bookings, invoices and questionnaires.

The plugin connects Cursor to Yakusoku's remote MCP server, `https://yakusoku.com.au/api/mcp`, and adds a `wedding-planning` skill that tells the agent how to use its tools: find the wedding first, preview bulk changes before committing them, and ask before anything that contacts people or deletes.

After installing, open **Cursor Settings → Tools & MCP**, choose **Connect** next to yakusoku, sign in to Yakusoku and choose what Cursor can do. Without the plugin, the **Add to Cursor** button in Yakusoku's Settings → AI assistants adds the server alone.

Requires a Yakusoku account. Disconnect at any time from Settings → AI assistants in Yakusoku. Guide: https://yakusoku.com.au/guides/connect-ai-assistant-to-yakusoku
